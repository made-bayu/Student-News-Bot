### [**FlashDecoding++ with 2-bit AWQ** Achieves 120 Tokens/s on Mid-Range Laptops]

* **Summary**: A newly merged upstream commit in `llama.cpp` and vLLM introduces an optimized FlashDecoding++ kernel combined with sub-2-bit Activation-aware Weight Quantization (AWQ). The architecture eliminates standard matrix-vector serialization bottlenecks by caching cross-attention states directly into pinned host memory via asynchronous memory transfers. Benchmarks demonstrate that a 14B parameter dense model runs inference at ~120 tokens/sec across hybrid CPU-GPU setups, drastically reducing KV-cache bloat on small-context windows. Full technical documentation and commit benchmarks are available on the llama.cpp GitHub pull request tracking tree.
* **Practical Student Takeaway**: If you are locked into a 4GB or 6GB VRAM laptop (like a mobile RTX 3050), this makes testing 14B models viable for your AI Lab assignments without immediately throwing CUDA Out-Of-Memory (OOM) errors. Map your layer offloading directly using `n_gpu_layers` to keep the bulk of attention tensors in VRAM while streaming quantized weights through system RAM via `mmap`. For your Operating Systems or Distributed Systems course, this is a prime case study in page fault management and non-blocking I/O during hardware-constrained compute.
