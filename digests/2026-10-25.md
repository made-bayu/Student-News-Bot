### [**Ollama Adds Native EXL2 Backend Support for 4-Bit Multi-GPU Desktop Inference**]

* **Summary**: Ollama has officially merged native support for **EXL2 quantization formats**, bridging the gap between ExLlamaV2's high-speed GPU-bound inference and Ollama's local orchestration runtime. This update implements optimized CUDA kernels that bypass traditional GGUF CPU-GPU offloading overhead, allowing sub-5-bit models to saturate tensor core pipelines directly. For local setups, this translates to double-digit token generation speedups on consumer hardware without degrading perplexity scores. Detailed benchmarks and implementation pull requests are tracking live on the [Ollama GitHub Repository](https://github.com/ollama/ollama).
