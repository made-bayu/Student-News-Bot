### [**ExllamaV3 Core Reaches v0.9.1 with Exl3 Quantization for 6GB VRAM Laptops**]

* **Summary**: The ExllamaV3 engine just shipped v0.9.1, introducing the Exl3 quantization format which squeezes 8-bit model accuracy into arbitrary 2.5-bit to 4-bit per weight footprints without the perplexity drop seen in older AWQ methods. By optimizing native CUDA kernels for consumer mobile GPUs, it bypasses CPU offloading bottlenecks entirely on mid-range hardware. For local experimentation in Surabaya's dorms, this means running 14B parameter models smoothly on typical student rigs with RTX 3050/4050 6GB cards. Check out the release notes and implementation benchmarks on the [ExllamaV3 GitHub Repository](https://github.com/turboderp/exllavamodel).
