### [**llama.cpp Merges Native BitNet b1.58 Kernel Support: Sub-2.5GB RAM LLM Inference on Budget CPUs**]

* **Summary**: The `llama.cpp` upstream repository just merged PR #11842, implementing native 1.58-bit ternary quantized tensor kernels (`i2_s` and `t1_58`) optimized directly for x86 AVX2 and AVX-512 SIMD vector instructions. This architecture bypasses standard matrix-multiplication heavy compute by replacing floating-point operations with addition and subtraction, drastically reducing memory bandwidth constraints. As a result, 8B ternary foundation models (such as BitNet-b1.58 checkpoints) can run entirely on consumer CPU RAM with an active working set under 2.3 GB while sustaining 14+ tokens/sec. Full implementation details and benchmarks are live on the [ggerganov/llama.cpp GitHub repository](https://github.com/ggerganov/llama.cpp).
* **Practical Student Takeaway**: You do not need an RTX 40-series laptop to build local agent workflows anymore—this runs flawlessly on an entry-level Core i5/Ryzen 5 laptop without touching an external GPU or thermal throttling. For curriculum integration, this is prime empirical material for your *Computer Architecture* or *Operating Systems* coursework, particularly for profiling cache-line misses (`perf stat`) and evaluating vector register utilization during memory-bound inference. Use this implementation to architect lightweight local assistants for your *Tugas Akhir (TA)* running on low-cost edge hardware like the Raspberry Pi 5.
