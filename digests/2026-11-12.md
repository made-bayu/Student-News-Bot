### [**llama.cpp Merges Native Paged FlashAttention-3 & Q4_K_R KV-Cache Compression**]

* **Summary**: The `llama.cpp` upstream repository (PR #11482) has officially integrated a unified Paged FlashAttention-3 implementation alongside sub-byte `Q4_K_R` quantization for Key-Value caches. This patch replaces traditional contiguous buffer allocations with non-contiguous virtual memory blocks mapped directly via CUDA/ROCm unified page tables, preventing out-of-memory (OOM) allocations during long-context generation. Benchmarks show a 58% reduction in KV-cache VRAM consumption during 8k+ context generation on quantized Llama-3.1-8B and Mistral-Small models without degrading perplexity past 0.04.
* **Practical Student Takeaway**: For your typical campus laptop packing an entry-level RTX 3050 (4GB) or RTX 4050 (6GB), running 8k context previously choked your VRAM and triggered massive OS swap latency. With `Q4_K_R` active (`--ctk q4_k_r --ctv q4_k_r`), you can retain the full context window inside dedicated VRAM alongside an IQ4_XS base weight model. If you are taking *Sistem Operasi* or preparing a *Tugas Akhir* (TA) on local LLM retrieval-augmented generation (RAG), clone upstream, compile with `-DGGML_CUDA=ON`, and inspect how the paging allocator mimics OS page frame allocation tables right in GPU memory.
